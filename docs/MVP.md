# MVP acceptance criteria

A release qualifies as the first useful MVP when a Windows 10/11 x64 user can:

1. Install and launch TBH Core without administrator rights.
2. Have the application discover or manually select the TBH save.
3. Launch Task Bar Hero and see data-source health.
4. Complete runs and see stage, duration, outcome, XP, Gold, DPS, and other supported measured values.
5. Persist those runs across application restarts.
6. See trustworthy Active XP/h, Session XP/h, Active Gold/h, and Session Gold/h.
7. Compare at least two measured stages.
8. Receive a best-measured-XP and best-measured-Gold recommendation with sample confidence.
9. See clear warnings when a source is unsupported, stale, or conflicts with another source.
10. Export run/history data as CSV or JSON.
